# LLM Gateway Web

Interface executiva e operacional do **LLM Gateway**, projetada segundo os princípios de design do **Apple Human Interface Guidelines (HIG)** para a web.

## Visão Geral

- **Tecnologias**: React 19, TypeScript, Vite, Vitest, Testing Library e ESLint.
- **Design System**: Tokens semânticos Apple HIG (modo Claro, Escuro e Alto Contraste), superfícies translúcidas com suporte estrito a `prefers-reduced-transparency`.
- **Conectividade**: Comunicação com o backend LLM Gateway via Edge Proxy (`:8787`).
